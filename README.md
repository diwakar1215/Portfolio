## 🚀 Getting Started

### 1) Clone

```bash
git clone https://github.com/diwakar1215/Portfolio.git
cd Portfolio
```

### 2) Install

```bash
npm install
```

### 3) Run locally

```bash
npm run dev
```

### 4) Build for production

```bash
npm run build
```
